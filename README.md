## 🎲 Jogos Disponíveis

### [Story Weave](https://vitruvia.github.io/jogos/story-weave/) 📖

Jogo colaborativo de narrativa presencial. Gere personagens ricos e palavras balanceadas para criar histórias em grupo.

- **Tecnologia:** HTML, React, Tailwind CSS
- **Jogadores:** 2-8 (presencial)
- **Duração:** 15-45 minutos
- **Status:** ✅ Disponível

<details>
<summary>Ver features</summary>

- ✨ Geração automática de personagens complexos
- 🎯 Sistema de balanceamento gramatical de palavras
- 🏆 Checkpoints com mecânicas especiais
- 📱 Mobile-first (otimizado para celular)
- 🎨 Design editorial/literário
- 🔄 Sistema de rodadas e turnos
- 🎲 5 temas narrativos (mistério, aventura, fantasia, cotidiano)
- 📊 Controle de raridade de palavras

</details>
